# Surrounding frames changed a visual defect classification

- **Search terms:** single-frame observation, apparent residue, clipped portrait, scene transition, sequential text, transient display
- **Observed scope:** Dialogue and scene-transition observations in a SNES game.
- **Failure context:** Momentary views of partial text, portraits, and leftover fragments were recorded as persistent clipping or residue.
- **Discriminating evidence:** Replaying the same ROM through the surrounding dialogue and transition showed complete text and portraits after output advanced, and the fragment disappeared as the field resumed. Another suspected overlap remained adjacent to an icon but did not visibly cover the letters on closer inspection.
- **Established result:** The observations no longer supported the earlier persistent-defect classification. This was a correction to the evidence record, not a code fix or proof that the animation matched the source game.
- **Transfer limit:** Relate a suspect frame to preceding and following frames, input, and display state to distinguish an expected intermediate view from a defect. Disappearance alone does not establish acceptable behavior; the claimed timing and presentation determine the comparison needed.
