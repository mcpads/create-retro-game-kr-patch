# Mega Drive 국소 사례

## MD-001

- **관측 범위:** Mega Drive 마도물어의 이벤트 스크립트.
- **사고 맥락:** 번역 과정에서 대화 종료와 컷신 종료 코드가 빠진 항목은 버튼을 눌러도 진행하지 않는 상태로 이어졌다. 반대로 선행판이 한 항목 안의 내용을 다음 항목으로 나눈 경우에는 단순 집합 비교가 누락으로 오인했다.
- **결정 실험:** 원본·번역의 제어코드를 항목별로 전수 비교하고, 종료 코드가 없으면 진행 불가로 분류하되 인접 항목의 분할 구조까지 확인해 잘못된 경고를 걸렀다.
- **확정 결론:** 실제 종료 코드가 빠진 항목은 진행을 멈췄고, 선행판이 내용을 인접 항목으로 나눈 경우는 단순 집합 비교의 잘못된 경고였다.
- **전이 한계:** 제어코드 집합 일치는 순서·인자·실행 중 의미까지 증명하지 않는다.
- **관련 판단 기준:** `references/strategy/build-and-verify.md` §5, `references/strategy/text-extraction.md` §2.

## MD-003

- **관측 범위:** Mega Drive 마도물어의 16×16 가변폭 글리프 데이터와 해당 글리프 선택 소비자.
- **사고 맥락:** 글리프마다 비슷한 블록 네 개가 이어져 중복 데이터나 미사용 영역처럼 보였다. 한 복사본만 생성하면 정렬 위치에 따라 글자가 사라지거나 잘릴 수 있었다.
- **검증 근거:** 소비자 역어셈블에서 X 좌표의 하위 2비트가 네 복사본 중 하나를 고르는 것을 확인했다. 생성기도 글리프를 0·1·2·3픽셀씩 옮긴 네 상태를 만들었다.
- **확정 결과:** 반복처럼 보인 네 블록은 가변폭 그리기의 정렬 상태를 위해 미리 이동시킨 복사본이었다.
- **전이 한계:** 다른 표시 루틴은 복사본 선택식·합성 방식·좌표 단위를 추적해 필요한 이동 상태를 다시 산정한다.
- **관련 판단 기준:** `references/strategy/font-strategy.md`, `references/strategy/runtime-assets.md`, `references/strategy/debugging.md`.
